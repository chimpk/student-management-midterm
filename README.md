# Realtime Student Information Management App

## Introduction
A real-time student information management application using Android and Firebase Firestore.

## Features by Role
- **Admin**: Full access, create accounts.
- **Manager**: All student-related functions (list, add, update, delete, import/export).
- **Employee**: View-only access, change own profile picture.

## Tech Stack
- **Platform**: Android (Java), min SDK 24+
- **Database**: Firebase Firestore
- **Architecture**: MVVM

## Setup & Run Guide
1. **Android Studio**: Use the latest version.
2. **JDK**: JDK 17 recommended.
3. **Firebase**: Create a Firebase project, enable Firestore.
4. **google-services.json**: Download and place in `app/` (see `google-services.json.example`).
